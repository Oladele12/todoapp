A simple and clean Todo application.

## Overview

This TodoApp lets you quickly add tasks and mark them as completed with a single click.  
Once you type a task and hit enter (or submit), it gets added to your list.  
Clicking on a task will cross it out, indicating that it’s completed.

## Features

- Add new tasks easily
- Click on a task to mark it as completed (crossed out)
- Simple, intuitive, and lightweight

## How It Works

1. Type your task into the input field.
2. Press **Enter** or click **Add** (depending on your UI) to add the task to the list.
3. Click on a task to mark it as completed — it will appear crossed out.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/todoapp.git
   ```
2. Open the project folder:
   ```bash
   cd todoapp
   ```
3. Open the `index.html` file in your browser.

> No frameworks or build tools needed — it's a lightweight app!
